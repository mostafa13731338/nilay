# وب‌سایت تجاری نیلای ترید (Nilay Trade)

وب‌سایت رسمی و مدرن توسعه صادرات و تجارت بین‌الملل شرکت بازرگانی نیلای ترید، پیاده‌سازی شده با **React 19 + TypeScript + Vite + Tailwind CSS**.

---

## 🚀 راهنمای نصب و اجرای محلی (Local Development)

### پیش‌نیازها:
- Node.js (نسخه ۱۸ یا بالاتر)
- npm یا pnpm یا yarn

### مراحل اجرا:
۱. در پوشه اصلی پروژه، دستور زیر را برای نصب وابستگی‌ها وارد کنید:
```bash
npm install
```

۲. برای اجرای سرور محلی توسعه:
```bash
npm run dev
```
سپس مرورگر خود را باز کرده و به آدرس `http://localhost:3000` (یا پورتی که ترمینال اعلام می‌کند) مراجعه کنید.

۳. برای ساخت نسخه نهایی جهت انتشار (Build):
```bash
npm run build
```
فایل‌های کامپایل‌شده در پوشه `dist` ایجاد می‌شوند و آماده قرارگیری روی هر هاست، سرور یا هاست‌های استاتیک هستند.

---

## ⚡ استقرار روی Netlify (Netlify Deployment)

این پروژه کاملاً برای **Netlify Forms** و میزبانی استاتیک بهینه شده است:
- **فرم مشاوره و فرم تماس**: تنظیمات به گونه‌ای انجام شده که ارسال اطلاعات به صورت `application/x-www-form-urlencoded` و با متد `POST` به ریشه دامنه انجام می‌شود.
- **شناسایی خودکار در زمان Build**: کدهای فرم پنهان با ویژگی `netlify` در فایل `index.html` تعریف شده‌اند تا سرور Netlify در زمان انتشار سایت، فرم‌ها را خودکار شناسایی کند.
- **پاسخ مستقیم (Reply-To)**: فیلد ایمیل با نام استاندارد `name="email"` و فیلد شماره تماس با نام `name="phone"` در فرم‌ها قرار داده شده‌اند.
